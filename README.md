# Hildemors Modernisering

Første versjon av ny Hildemors-side bygget med Next.js, Vercel-retning og statiske data basert på Høst 2026-planen.

## Lokal utvikling

```bash
pnpm install
pnpm dev
```

Åpne `http://localhost:3000`.

## Førsteversjon

- Public forside med Hildemors-uttrykk.
- Public Kurs-tab med kurstyper fra originalsidens innhold.
- Public Timeplan med reelle Høst 2026-kurs.
- Guidet påmeldingsflyt med foresattinfo og versjonerte kursvilkår.
- Admin-prototype for kurs, semester/timeplan og resepsjonsinnsjekk.
